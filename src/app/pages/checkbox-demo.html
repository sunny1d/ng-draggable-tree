复选框：三态级联 / 独立勾选

权限字典树

已勾选 {{ checked().length }} 项 @for (name of checked(); track name) { {{ name }} }

当前规则

  • 开启useCheckbox 每行显示复选框
    • @if (triState()) {
  • useTriState = true：勾选状态以叶子为单元存储，父节点状态由子树统计派生
  • 全部叶子勾选后父节点显示已勾选
  • 部分勾选时父节点显示半选（indeterminate）
  • 点击父复选框会整组勾选 / 取消
    • } @else {
  • useTriState = false：父子互不联动，每行只切换自身
  • 不存在半选态，父节点也可被独立勾选 / 取消
  • 勾选集合即「被勾选的节点」本身
    • }
  • 键盘：↑/↓ 移动焦点，Space 切换勾选
